# Dryuf Jackson

Set of common utilities Jackson serialization.

## Release

```
<dependency>
	<groupId>net.dryuf</groupId>
	<artifactId>dryuf-jackson</artifactId>
	<version>1.0.0</version>
</dependency>
```


## SecureFieldsWriter

Role based write access to POJO objects.  Code automatically rejects any attempt to modify object beyond user
permission.
